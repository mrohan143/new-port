Place your images here:

- profile.jpg   -> used in the Hero section
- about.jpg     -> used in the About section
- project-1.jpg -> Project 1 thumbnail
- project-2.jpg -> Project 2 thumbnail
- project-3.jpg -> Project 3 thumbnail
- project-4.jpg -> Project 4 thumbnail
- og-cover.jpg  -> (optional) image shown when the site is shared on social media

If an image file is missing or fails to load, the site automatically shows a
clean placeholder block instead of a broken image icon, so nothing looks broken
before you add your real photos.
